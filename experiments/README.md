# XVC 剪贴板可行性原型

**状态修正：浏览器自定义数据读写验证通过，但它不生成标准视频/文件剪贴板条目。用户看到剪贴板中没有视频符合该原型的类型限制；本原型未通过实际“复制视频”的产品验收。**

第二轮新增标准 `video/mp4`（默认，不回退）与复制事件 `File` 探测入口，两者均没有生成 Finder 可粘贴的文件。要重现第一轮自定义数据实验，须在类型选择框手动选择 `web video/mp4`。另有仅用于诊断的 [原生内存对照](native-memory/README.md)；它也未通过 Finder 粘贴验收，不是产品方案。正式实现结果见 [验证记录](../docs/validation.md)。

这是回答一个问题的验证版：**纯 Chrome / Edge 扩展能否将不超过 25MB 的完整 MP4 字节写入 macOS 系统剪贴板，并在源对象释放、写入浏览器退出后完整读回？**

视频在扩展内获取和处理，不调用本地文件 API，不创建本地 MP4，不安装 Native Messaging 助手。此版本仅验证 `web video/mp4` 数据剪贴板，不验证其他应用的粘贴。

## 加载扩展

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启开发者模式，选择“加载已解压的扩展程序”。
3. 选择项目中的 `experiments/extension` 目录。
4. 点击扩展的工具栏图标，打开验证页。默认使用 MDN 的公开 MP4 示例，无需本地服务器。
5. 默认尝试标准 `video/mp4`，当前 Chrome 会明确报告不支持。可再点击“探测复制事件中的 File”，并检查系统类型或 Finder 粘贴结果。
6. 仅在需要复现第一轮数据读写对照时，手动选择 `web video/mp4`，再读取、释放源视频并读回；此对照通过也不能算视频文件复制成功。

写入会覆盖当前系统剪贴板。界面显示实际字节数、SHA-256、MP4 box、视频分辨率和时长。验证页使用额外的原型标记，只处理其刚写入的测试视频，不监控剪贴板。

原型申请 `clipboardRead` 是为了手动读回测试；正式仅复制的版本应去掉该权限。它未申请 `downloads`、`nativeMessaging` 或本地文件访问权限。

## 运行大小边界测试源

项目根目录一条命令，无需安装 npm 依赖：

```sh
npm run experiment:web
```

服务器只监听 `127.0.0.1:4173`，提供开发用测试视频和已列出的静态资源。扩展从 HTTP 请求取得它们，不通过文件路径读取视频。这是可选的测试基础设施，不是产品需要安装的本地助手。

页面中的测试源按钮提供：

- 43,528 字节的合成视频。
- 24,999,999 字节与恰好 25,000,000 字节的有效 MP4。
- 25,000,001 字节的超限响应。
- 无 `Content-Length` 的超限响应。
- 冒充 MP4 的错误内容。

大尺寸样本由同一段 2 秒视频追加合法 `free` box 构成，用来验证字节容量边界；它不代表一段实际编码了 25MB 图像数据的视频。

## 数据流

网络请求 → 累计实际字节 → 校验 MP4 box 和视频元数据 → SHA-256 → `ClipboardItem` → 系统剪贴板。

剪贴板 item 中包含：

- `web video/mp4`：完整 MP4 二进制。
- `web application/x-xvc-probe+json`：本原型的随机任务 ID、长度与摘要，仅用于验证。

内容是 MP4；剪贴板表示是 Web 自定义类型，不是原生文件列表。不把 MIME 标签当作转码，也不把“已写入”当作第三方应用支持粘贴。

## 当前范围

已经提供视频原生右键菜单实验入口。右键后的验证页仅接受允许来源的直接 MP4 HTTP(S) 地址。

尚未实现 X 的 `blob:` 播放器地址解析、推文与多媒体精确关联、播放覆盖层命中，以及不打开验证页的最终单次右键体验。当前原型不能直接视为完整 X 首页复制插件。

在焦点丢失时保留准备好的内存视频，提示返回验证页再写入；不强抢焦点。样本结构与元数据检查不是完整恶意媒体安全扫描。

## 测试样本来源

`../tests/fixtures/sample.mp4` 是用 FFmpeg 从合成图像生成的 320×180、15fps、2 秒、无音频 H.264 MP4，不包含用户数据：

```sh
ffmpeg -f lavfi -i 'testsrc2=size=320x180:rate=15' -t 2 -an \
  -c:v libx264 -pix_fmt yuv420p -movflags +faststart tests/fixtures/sample.mp4
```

公开网络样本：[MDN flower.mp4](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4)。

正式实现的测试范围见 [验证记录](../docs/validation.md)。
