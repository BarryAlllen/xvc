# XVC 验证记录

验证日期：2026-10-15。环境为 macOS Apple Silicon。下列核心功能验证对应 v0.1.0；v0.1.1、v0.2.0 与 v0.2.1 的验证另列于文末。

首个公开版本编号为 v0.1.0。发行构建显式指定最低 macOS 13，不依赖构建机器的默认部署版本；并非所有 macOS 版本均已实测。

## 自动化检查

`npm test` 共 11 项通过：

- MAIN / ISOLATED 两个浏览器执行环境的独立初始化。
- 只接受 X 视频 CDN 的完整 MP4 地址。
- 引用推文、多视频匹配与过期元数据拒绝。
- 必须收到原生 `public.file-url` 与显式回读确认，下载完成本身不能报告复制成功。
- 错误来源、子框架及非视频地址拒绝。
- 失联、导航和关闭标签页的任务处理。
- 扩展、本地程序和 npm 元数据的版本一致性与 MIT 许可证检查。

`npm run test:native` 共 14 项通过：

- 消息头与正文分段传输。
- 合成 MP4 的下载、内容校验、SHA-256 与系统文件剪贴板回读。
- 24,999,999 字节与恰好 25,000,000 字节均成功。
- 超过 25,000,000 字节时拒绝，包含未知 Content-Length 情况。
- 新任务开始前删除旧视频、近期下载残留和状态记录，新任务失败也不恢复旧文件。
- 清理缓存中的符号链接时保留链接指向的外部文件。
- HTML 冒充 MP4、非允许来源跳转、任意本地文件和非 X 来源均拒绝。
- 超限清晰度回退到更小的 MP4。
- 多个原生任务同时运行时，后一个返回 BUSY，活动下载不被删除。
- 下载取消与失败后的半成品清理。

大尺寸边界样本是在合成短视频中追加合法 `free` box，用于验证容量限制，不代表所有视频编码或长视频的兼容性。

## 实际使用验证

- Chrome 已加载正式扩展，并确认与安装后的原生程序连接。
- 在真实 X 推文详情页和首页完成视频右键复制。
- 0.1.0 首页样本为 14,518,270 字节，顶部提示显示「复制成功」；独立诊断确认系统文件 URL 可读取、稳定，文件大小和 SHA-256 一致。
- 下载前缓存中有 3 个历史 MP4；任务结束后只保留当前 MP4 和状态记录。
- 顶部提示不遮罩页面，下载期间可继续操作页面；成功提示会自动消失，取消与超限提示已实测。
- 同一原生文件引用写法此前已由使用者确认可粘贴到微信。不同接收应用是否支持文件粘贴，取决于其自身能力。

公开版本保留结果摘要；本机剪贴板原始快照、账号页面截图及下载缓存不随源码或安装包分发。

## v0.2.0 设置与缓存验证

- `npm test` 的 14 项检查通过，包含旧宿主能力检查、设置来源限制和拒绝通过普通设置更新指定任意目录。
- `npm run test:native` 的 20 项检查通过：在原有验证上覆盖设置持久化和参数拒绝、自定义上限的精确边界及未知长度流、无限制下载超过原 25 MB 的样本、保留缓存、跨目录操作锁、无效目录不覆盖设置、更改目录和恢复全部默认值。
- 原生文件名断言符合 `xvc-yyyy-mm-dd-12hex.mp4`；保留模式下新旧文件名不同，旧视频仍存在。
- Chrome 实际验证：拖动大小保存、无限制时滑条禁用、保留开关刷新读回、打开 Finder、修改测试目录、恢复全部默认设置并刷新读回。
- Edge 实际验证：已加载 v0.2.0，连接本地程序；无限制刷新后仍开启；无效目录保存失败时原路径不变、输入保留；恢复默认成功。
- Edge 真实 X 首页右键复制得到 16,448,301 字节的完整视频，新命名规则生效。独立只读诊断确认文件大小与 SHA-256 一致，当前系统 `public.file-url` 引用稳定、文件可读。此次不将该视频或账号页面随源码分发。
- 弹窗固定为 440 CSS px，修复工具栏浮层因视口约束变窄的问题；作者和仓库入口可完整显示。深浅配色均已实际查看。完成一轮独立视觉评审，统一开关主标签字号并精简重复说明。
- 动效使用按压反馈、开关滑动及轻量出场，支持系统减少动态效果。未单独采集过渡过程帧，不将静态截图作为动效验收依据。

## v0.2.1 静音回归修复验证

- 修复前在 Chrome 的真实 X 视频上复现：按下右键后、选择「复制视频」前，播放器从 Unmute（静音）变成 Mute（有声），浏览器显示正在播放音频。
- 新增 5 项交互回归测试，运行实际 content script 并模拟网站的委托播放事件。修复前静音、原有音量、Control＋点击的 3 项断言失败；修复后全部通过。正常左键和视频区域外的操作不被拦截。
- `npm test` 共 19 项通过；`npm run build` 完成。ZIP 完整性与 SHA-256 校验通过，扩展、本地程序和包内元数据均为 v0.2.1。
- Chrome 与 Edge 均已加载新版扩展，设置页确认「本地程序已连接 · v0.2.1」。
- 两个浏览器均在真实 X 视频上验证右键菜单和复制下载，视频始终保留静音。下载成功后，原生程序已完成文件剪贴板写入、回读及成功记录。
- Edge 另验证正常左键可以开启声音；原本有声时右键不会强制静音，随后将测试视频恢复静音。未用强制修改播放器音量的方式修复。
- 本次只修改页面鼠标事件处理，本地程序除版本号外无功能变更，未重复运行会覆盖剪贴板的原生集成测试；v0.2.0 的 20 项原生验证记录仍保留。

## 本地复现

在 macOS 安装 Node.js 与 Xcode Command Line Tools 后：

```sh
npm run build
npm test
npm run test:native
```

原生测试使用独立测试缓存，并会覆盖系统剪贴板为合成视频文件引用。界面测试页可通过 `npm run dev` 启动，只监听 `127.0.0.1:4173`，不属于正式运行依赖。
