# XVC 安装与使用说明

适用版本：0.1.1。当前安装包面向 macOS 13 或更新版本、Apple Silicon（M 系列芯片），支持 Chrome / Edge。Chrome 已完成真实 X 视频复制验证；Edge 已提供安装配置，尚未完成完整实测。并非所有 macOS 版本均已逐一验证。

XVC 由浏览器扩展和一个本地程序组成。扩展提供视频右键菜单与顶部小提示；本地程序负责下载 MP4、清理自己的缓存、将文件引用写入 macOS 剪贴板。

安装前请查看 [系统要求与兼容性](compatibility.md)。Chrome 声明最低版本为 116，Edge 完整链路待验收；当前 ZIP 不能作为油猴脚本安装。

## 首次安装

### 1. 解压安装包

解压 `XVC-macOS.zip`，将得到的 `XVC` 文件夹放到一个准备长期保留的位置。

文件夹中包含：

| 文件 | 用途 |
| --- | --- |
| `extension/` | Chrome / Edge 浏览器扩展 |
| `安装 XVC.command` | 安装本地程序并配置两种浏览器 |
| `卸载 XVC.command` | 移除本地程序及浏览器连接配置 |
| `xvc-host` | 已编译的本地可执行程序 |
| `使用说明.md`、`docs/` | 说明与验收记录 |

使用者无需安装 Node.js、Python、Swift 或 Xcode。不要只拿走 `.command` 文件，它需要同一文件夹中的 `xvc-host`。

### 2. 安装本地程序

双击「安装 XVC.command」，终端显示「XVC 本地程序已安装，支持 Chrome / Edge」后即可关闭该窗口。

这是当前用户级安装，不需要管理员权限。安装器会复制 `xvc-host`，并写入 Chrome / Edge 的 Native Messaging 配置。本地程序由浏览器按需启动，任务结束后退出，无需手动保持终端运行，也没有常驻服务或本地 HTTP 端口。

当前开发包尚未签名、公证。若 macOS 阻止运行，可核对来源后使用 Finder 的「右键 → 打开」，或按系统提示在「系统设置 → 隐私与安全性」允许本次运行。

### 3. 加载浏览器扩展

1. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
2. 开启页面中的「开发者模式」。
3. 点击「加载已解压的扩展程序」（部分界面显示「加载未打包的扩展程序」）。
4. 选择刚解压的 **`XVC/extension` 文件夹**，不是整个 `XVC` 文件夹，也不是 ZIP 文件。
5. 确认页面出现「XVC — X Video Copy」，版本为 0.1.1，开关已开启。

Chrome 和 Edge 各自需要加载一次扩展。本地安装脚本运行一次，就会配置两种浏览器。

扩展 ID 应为：

```text
naknhmocnkgeckbgghnopeifpenpilej
```

加载后请保留 `extension` 文件夹及其原路径；移动或删除它会影响浏览器加载插件。本地程序虽然已复制安装，浏览器扩展仍从所选择的目录读取。

### 4. 检查连接并刷新 X

1. 点击浏览器工具栏的扩展程序图标，找到 XVC 并打开。
2. 确认显示「本地程序已连接 · v0.1.1」。可按需将 XVC 固定到工具栏。
3. 打开或刷新 `https://x.com/`。如果 X 要求登录，请先正常登录。

安装或重新加载扩展后，需要刷新已有的 X 页面，才能开始识别页面加载的视频信息。

## 日常使用

在推文的**视频画面内**右键 →「复制视频」→ 等待顶部小提示显示「复制成功」→ 到支持文件粘贴的应用按 **⌘V**。

- 正文和图片区域不会显示 XVC 菜单。
- 点击「复制视频」后直接开始下载，顶部显示一行进度，不遮罩页面，可以继续浏览。
- 只有写入系统文件剪贴板并回读确认后才显示成功，成功提示约 2 秒后消失。
- 下载过程中点提示右侧的 × 可取消。
- 大小上限为 **25,000,000 字节（25 MB，含边界）**。当前清晰度过大时会尝试更小的 MP4，全部超限才提示不能复制。
- 当前支持完整 MP4，不支持只提供 HLS / 分段流的视频。接收应用是否接受视频文件粘贴，取决于其自身能力。

## 本地程序和缓存装在哪里

`~` 表示当前用户的个人目录，例如 `/Users/你的用户名`。

| 项目 | 安装位置 |
| --- | --- |
| 本地可执行程序 | `~/Library/Application Support/XVC/xvc-host` |
| Chrome 连接配置 | `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.xvc.native.json` |
| Edge 连接配置 | `~/Library/Application Support/Microsoft Edge/NativeMessagingHosts/com.xvc.native.json` |
| 当前视频缓存 | `~/Library/Caches/XVC/videos/` |

你说的「本地脚本」实际分为两部分：`安装 XVC.command` 是安装时运行的脚本，留在解压的安装包中；安装后被插件调用的是已编译的 `xvc-host` 程序。

**安装后的程序路径：**

```text
~/Library/Application Support/XVC/xvc-host
```

在 Finder 按 **⌘⇧G**（前往文件夹），输入下面的目录即可找到它：

```text
~/Library/Application Support/XVC/
```

视频缓存同样可以通过 Finder「前往文件夹」打开：

```text
~/Library/Caches/XVC/videos/
```

缓存仅保留当前视频及 `current.json` 状态记录。每次新下载开始前，清除所有历史 XVC 视频和未完成下载。即使新任务失败或取消，上一份视频也不恢复。剪贴板保存的是原生文件引用，因此删除旧缓存后，旧视频便不能再通过该引用粘贴。

本地程序只接受固定 XVC 扩展发起的任务，只从 `video.twimg.com` 下载完整 MP4，不接受任意本地路径或脚本命令。

## 更新版本

1. 等待正在下载的任务结束或取消。
2. 解压新版安装包，再运行新版「安装 XVC.command」，更新已安装的本地程序。
3. 用新版 `extension` 文件夹内容替换浏览器原来加载的目录内容，保持原目录路径不变。
4. 打开浏览器扩展管理页面，点击 XVC 卡片上的「重新加载」。
5. 刷新已有的 X 页面，再打开 XVC 检查本地程序版本。

如果使用源码开发版，扩展目录是项目中的 `extension/`，更新后应重新加载这一份。

## 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 显示本地程序未连接 | 重新运行同版本的「安装 XVC.command」，确认扩展 ID 正确，再点「重新检查连接」 |
| 视频右键没有 XVC 菜单 | 确认插件已启用并刷新 X；右键位置必须在视频画面中 |
| 提示未找到完整 MP4 | 刷新 X 后重试；仅有分段流或无法确认对应视频时暂不支持 |
| 提示另一个视频正在复制 | 等待另一窗口或浏览器中的 XVC 任务结束后重试 |
| 已复制，但目标应用无反应 | 确认该应用支持文件粘贴，并且此后没有开始新的 XVC 下载或清理缓存 |

## 卸载

1. 运行安装包中的「卸载 XVC.command」，删除本地程序及 Chrome / Edge 的连接配置。
2. 在浏览器扩展管理页面移除 XVC。
3. 卸载会保留视频缓存；如不再需要，可自行删除 `~/Library/Caches/XVC/`。

卸载不会修改其他浏览器扩展或其他应用的文件。
